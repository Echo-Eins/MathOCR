# MathOCR — отложенные исследования

Записано 2026-10-10 по решению автора: сейчас приоритет — финальная модель
задания (3 seed'а), всё ниже — следующая очередь. Цифры — стенд проб
(`scripts/probe.py`: 20k пар × 4 эпохи, Muon-контроль val edit 0,206/0,217;
логи в `/mnt/SSD/MathOCR/probe/runs/`).

## Что уже выяснено (чтобы не повторять)

- Подтверждено: Muon вместо AdamW (стенд и полный прогон); больше ячеек
  памяти на глиф — шаг энкодера 8×4 (0,157 при равных шагах), глиф 18/22 px
  (0,133 / 0,107 против контролей равных шагов 0,155 / 0,129).
- Нейтрально при 20k×4 (механизм при этом *работает*, проверено):
  AAS-shift, фовеа (следует за чтением, но декодер её не использует: +2 % CE
  при обнулении), фовеа на грубом энкодере и через учебный план, кольцевой
  приоритет в кросс-внимании (таблица выучила фовеальный профиль +0,8 / −1,0
  при LR×30), покрытие (сила до 1,8), деформируемое кольцевое чтение, голова
  счёта, inject, rings, depth_pos, большой холст, max_len 512.
- Хуже: AAS-sort, token dropout 0,15, подача счётчиков в декодер (CAN feed).
- Смешано: склейка многострочных формул p=0,3 — при равных шагах хуже на
  основных данных, лучше на CPE с эталоном > 254 токенов.
- Правило стенда: сравнивать только при равном числе шагов оптимизатора
  (крупные картинки и склейка меняют шаги на эпоху); новые скаляры, которые
  должны вырасти до O(1), проверять на выученные значения (`feedback_lr_mult`).

## 1. «Формула на странице» — огромный вход без потерь на сжатии

Цель: проверить, где фовеа / кольцевое чтение / AAS дают то, чего не даёт
стандартная модель.

- [ ] Генератор: формула из набора вклеивается в случайное место пустой
      страницы 2048×2048 (seeded по (seed, epoch, i)); позже — дистракторы
      (другие формулы, шум, линии).
- [ ] (а) Даунсемпл страницы в холст 192×768 — ожидаемый провал (глиф ~5 px).
- [ ] (б) Потолок: модель на вырезанной формуле.
- [ ] (в) Грубый энкодер (страница /4) + кольцевое деформируемое чтение
      дешёвых признаков *полного* разрешения (отдельный неглубокий stem) вокруг
      фокуса декодера; стоимость не зависит от размера страницы.
- [ ] (г) Плотный энкодер в полном разрешении — замер памяти/времени.
- [ ] Учебный план: старт с модели на вырезках, затем страницы.
- Критерий успеха: (в) близко к (б) при стоимости нескольких холстов формулы,
  (а) проваливается, (г) не помещается.
